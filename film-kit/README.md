# 영상·숏폼 루프 키트 (loop-starter-kit 영상판)

게임 키트(v2.5.0)의 **뼈대(일꾼+감독, 파일 기억, 훅, 비용 점검)** 는 그대로 쓰고, 게임 전용이던 부분을 영상용으로 바꾼 것.

| 게임 키트 | 영상 키트 |
|---|---|
| 엔진 검사(Unity/Godot) | `tools/film.py` (ffprobe·ffmpeg 로 규격·소리·검은 화면·정지·음량) |
| 3층: 게임 카메라 캡처 | 3층 프레임 컨택트시트 + **4층 시청자 눈**(첫 3초·무음·안전영역·끝까지·권리) |
| PlayerEye | ViewerEye |
| 마일스톤 끝 = 사람 플레이 | 에피소드 끝 = 사람 승인 (Publish) |
| 릴리스 | **업로드는 일꾼 금지, 사람 승인 뒤 감독** |
| (없음) | GPU 잠금, 성과 되먹임(metrics.csv), 승인 3개 쌓이면 정지, 3편 반응 없으면 정지 |
