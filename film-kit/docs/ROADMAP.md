# ROADMAP — 순서

> 루프는 INBOX 에 할 일이 없을 때 여기서 맨 위의 안 끝난 조각을 집는다. 조각 = 한 바퀴 크기 (한 에피소드의 한 단계 일부). **ID 는 안 바꾼다** (`Slice: EP01-S3-a`).
> 🔴 로 막힌 조각은 `[!]` + 이유. 사람만 할 수 있는 것(계정 로그인·새 모델 다운로드 승인)은 `[!] 사람:`.
> 렌더가 필요한 조각(S2·S3·S4)과 렌더 없는 조각(S1·S5·S6·S7)을 섞어 둔다 — GPU 가 잠겨 있어도 할 일이 있게.
