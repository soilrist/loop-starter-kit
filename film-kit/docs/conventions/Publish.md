# 올리기 규칙 (일꾼은 만들고, 사람이 승인하고, 감독이 올린다)

## 한 줄 요약
**일꾼은 업로드하지 않는다. 일꾼은 "올릴 수 있는 꾸러미"까지만 만든다.** 올리는 건 사람 승인 뒤 감독 (공식 API) 또는 사람.

## 왜
업로드는 되돌릴 수 없고(🔴 2 밖으로 나가는 것), 계정 정지·저작권·AI 라벨 문제가 걸린다. 무인으로 올리다 사고 나면 채널 전체가 위험하다.

## 꾸러미 (`publish/<에피소드ID>/`)
| 파일 | 내용 | 검사 |
|---|---|---|
| `final.mp4` | 완성본 | `film.py clip` 통과 + 3·4층 통과 |
| `thumb.jpg` | 썸네일 (유튜브용, 세로 쇼츠는 선택) | 눈으로 열어 글자 가독성 |
| `meta.json` | 플랫폼별 제목·설명·해시태그·예약 시각·AI 생성 표기 여부·음원 출처 | `film.py check` 가 필수 키 확인 |
| `CHECKLIST.md` | 시청자 눈 ⑤ 결과, 사용한 모델·음원·폰트 라이선스 | 비어 있으면 승인 불가 |

## 승인 흐름
1. 일꾼: 꾸러미 완성 → INBOX `승인: ep03 올려도 됨? (꾸러미 publish/ep03/, 4층 통과)` 한 줄 + 커밋
2. 감독: 영상 프레임을 **직접 열어 보고** 사람에게 3줄 보고 ("무엇 / 길이 / 걸리는 것 없음") — 폰으로 볼 수 있게 `SendUserFile`
3. 사람: "올려" 한마디
4. 감독: 공식 API 로 업로드 (YouTube Data API 등 / 인스타·틱톡은 공식 게시 API 가 허용하는 범위에서만, 없으면 사람이 앱에서) → INBOX `승인` 줄 삭제, `data/published.csv` 에 `날짜,플랫폼,에피소드,URL` 한 줄
5. **사람 눈 아닌 자동 업로드 스케줄(예약)도 승인된 꾸러미만.** 로그인 쿠키·비밀번호를 코드에 넣지 않는다 (API 키는 OS 키체인/환경변수).

## 성과 되먹임 (루프의 다음 방향을 정한다)
- 올린 지 2~3일 뒤 감독이 조회수·평균 시청 비율·구독 증가를 `data/metrics.csv` 에 적는다 (`date,episode,platform,views,avg_watch_pct,likes,shares`).
- 일꾼은 **새 에피소드 기획 바퀴**에서 metrics.csv 를 먼저 읽고, 평균 시청 비율이 높았던 훅·길이·주제 쪽으로 기울인다. 근거를 DESIGN §6 에 적는다.
- 3편 연속 평균 시청 비율이 목표(DESIGN §6)에 못 미치면 감독이 사람에게 "방향을 바꿀까요?" 한 줄 (🔴 1).
