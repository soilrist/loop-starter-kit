# 검사 규칙 (영상판)

## 한 줄 요약
**"틀린 걸 찾으려고 본다."** 영상은 안 열어 보면 틀린 게 안 보인다. 만들었다고 통과가 아니다.

## 검사 4층 (아래부터, 아래가 실패하면 위로 안 올라감)
| 층 | 무엇 | 도구 | 실패하면 |
|---|---|---|---|
| 1. 기계 검사 | 대본·샷리스트 JSON, 금지어, 총 길이, 자리표시 / 완성 영상의 해상도·fps·길이·소리 있음·음량·검은 화면·정지 | `python3 tools/film.py check` · `python3 tools/film.py clip <mp4>` | 커밋 금지 |
| 2. 흐름 검사 | 자막이 소리와 맞나(싱크), 컷 순서가 대본대로인가, 입모양/음성 길이, 클립 이음새 | `docs/checks/film.md` 의 명령 (ffprobe 길이 비교, 자막 타임코드 대조) | 커밋 가능, 같은 바퀴에 fix |
| 3. 눈 검사 | 프레임을 **실제로 열어** 얼굴·손·글자 깨짐·캐릭터 일치·화풍 일치 | `python3 tools/film.py sheet <mp4>` 로 프레임 모음 → Read 로 열기 | 같은 바퀴에 fix, 못 고치면 INBOX `막힘` |
| 4. 시청자 눈 | 처음 보는 사람이 끝까지 보나 (`ViewerEye.md` 다섯 칸) | 첫 3초 프레임·소리 끈 상태·폰 안전영역 | 같은 바퀴에 fix |

## 규칙
1. **못 한 검사는 "통과"가 아니라 "못 함".** "통과"는 실제 명령을 돌리고 출력 마지막 줄을 STATUS 에 **글자 그대로** 인용했을 때만. 예: `1층 통과(\`✔ 영상 검사 통과 (ep01.mp4 1080x1920 30fps 42.0초 / 오류 0)\`)`. loop.sh 가 도구 기록과 대조한다.
2. **1·2층 인용은 `python3 tools/jev.py evidence "<무슨 검사>" "<인용>"` 이 `SUPPORTED` 일 때만 통과.**
3. **3·4층 "통과"는 프레임 그림을 Read 로 열었을 때만이다.** 어느 그림을 봤는지 적는다 (`captures/ep01_sheet.jpg`). 눈으로 본 판정은 Jev 에 묻지 않는다. 안 열었으면 "못 함".
4. **영상 한 편을 통째로 못 본다 — 그래서 프레임으로 본다.** 컨택트시트(균등 12장) + **첫 3초(훅) 3장** + 컷 이음새 앞뒤 프레임. 움직임이 문제인 조각(걷기·손동작)은 같은 컷에서 0.3초 간격 6장.
5. **자리표시·금지·길이는 눈이 아니라 코드로.** `film.py check` 가 잡는다.
6. **통과한 영상의 정확한 파일을 승인 후보로 올린다.** 검사 후 다시 인코딩하면 검사를 다시 한다 (해시가 바뀌면 다른 영상).
7. **같은 지적 두 번 → 규칙으로 올리고 → 검사로 만든다.** (예: "손가락 6개" 가 두 번 나오면 3층 체크리스트에 항목 추가, "자막이 하단 UI 에 가림"이 두 번이면 `film.py` 에 안전영역 검사 추가)
8. **GPU 는 하나다.** 렌더 전에 `loop/gpu.lock` 을 확인한다 (`docs/checks/film.md` 4). 다른 작업(릴스 공장·밤이 루프)이 쓰는 중이면 그 조각은 건너뛴다.

## 3층 체크리스트 (프레임)
- [ ] 얼굴 일그러짐·눈 4개·손가락 개수 이상 없음
- [ ] 글자(간판·자막 이미지)가 깨지거나 한글이 □ 로 안 보임
- [ ] 같은 인물이 컷마다 같은 얼굴·옷·머리인가 (`data/characters.json` 기준 프레임과 대조)
- [ ] 화풍(`data/style.json`)이 컷마다 같음 — 갑자기 실사/만화로 튀지 않음
- [ ] 컷 이음새에서 위치·방향·조명이 갑자기 안 바뀜 (의도한 장면 전환 제외)
- [ ] 이번 조각의 합격 문장(예: "대장장이가 망치를 든다")이 프레임에서 보임
- [ ] 워터마크·모델이 만든 이상한 글자·로고 없음
- 프레임 파일: `captures/<에피소드>_<설명>.jpg` — 합격 것만 커밋, 나머지 `captures/tmp/`
