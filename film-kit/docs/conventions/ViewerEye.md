# 시청자 눈 (4층) — 처음 보는 사람이 끝까지 보나

기계 검사가 전부 통과한 영상이 아무도 안 보는 일이 제일 흔하다. 만든 사람이 아니라 **스크롤하다 멈춘 사람**의 눈으로 다섯 칸을 본다.

| # | 칸 | 어떻게 보나 | 아니오면 |
|---|---|---|---|
| ① | **첫 3초 훅** | 0~3초 프레임 3장. 질문·충돌·궁금한 장면·큰 글자 중 하나가 있나? 로고·인사·설명으로 시작하면 아니오 | 첫 샷을 앞당기거나 훅 문장 자막 추가 |
| ② | **소리 없이도 이해** | 자막(대사·핵심 단어)이 화면에 있나? 숏폼 시청 절반은 무음 | 자막 추가 |
| ③ | **폰 세로 안전영역** | 위 15%·아래 25%·오른쪽 15% 에 자막·핵심 피사체가 없나 (플랫폼 UI 가 가린다) | 자막·구도 이동 |
| ④ | **끝까지 볼 이유** | 중간에 "다음이 궁금"한 지점이 있나, 마지막이 루프/다음 편 유도로 끝나나 (길이 대비 컷 전환 속도: 숏폼은 2~4초마다 변화) | 컷 순서·길이 조정 |
| ⑤ | **보내도 되나** | AI 생성 표기가 들어갔나(플랫폼 AI 라벨 설정 메모), 실존 인물·상표·남의 음악·남의 영상 없음, 금지어 없음 | 고치거나 INBOX `질문` (🔴 권리) |

STATUS 검사 칸 뒤에 `시청자 눈: ①예(captures/ep01_hook.jpg) ②예 ③예 ④아니오(중반 15초 정지 느낌→컷 추가함) ⑤예` 한 줄. `예` 에 근거(그림 파일·자막 파일)가 없으면 감독이 `결함`.
