# 프로필: content

**언제** — 결과물이 사람이 보는 파일일 때: 영상·쇼츠·릴스·글·이미지·썸네일, 그리고 그걸 올리는 채널 운영.

**결과물** — 올릴 수 있는 파일 + 올릴 때 쓸 글(제목·설명·태그). 조각 하나 = 편 하나의 **한 단계**(대본 / 소재 / 편집 / 올릴 묶음).

**검사 3층**
| 층 | 여기서 뜻하는 것 |
|---|---|
| 1 기계 | 파일이 열린다 + 규격(길이·해상도·비율·용량·글자 수)이 맞는다 — `ffprobe`·글자 수 세기 등 **명령 출력**으로 |
| 2 동작 | 처음부터 끝까지 실제로 재생·읽기: 소리 있음, 자막 싱크, 끊김·검은 화면 없음, 링크 열림 |
| 3 눈 | 프레임 캡처(시작·중간·끝)나 완성 글을 직접 보고 아래 다섯 칸 |

**쓰는 사람 눈 다섯 칸** (처음 보는 시청자·독자라 치고)
1. 첫 3초·첫 줄에 뭔 얘기인지 아는가
2. 끝까지 볼 이유가 앞에 걸려 있는가
3. 글자·자막이 작은 화면에서 읽히는가 (가려지는 곳 없음)
4. 제목·썸네일이 약속한 것을 본문이 지키는가
5. 채널의 다른 편과 같은 사람이 만든 것으로 보이는가 (톤·형식)

**이 종류의 🔴** — **올리기·예약 올리기·공개 범위 바꾸기·지우기**, 댓글·메시지 보내기, 돈 드는 생성(유료 크레딧), 남의 저작물·얼굴·목소리 쓰기, 사실 주장(숫자·인용)의 출처 없는 사용.

**여는 문서·스킬**
- 스킬: `build-slice`, `unblock`
- 설계서: `docs/DESIGN.md` — §1 채널·시청자, §5 편 목록(시리즈), §6 규격 숫자(길이·비율·올리는 요일), §7 톤·형식
- 편마다 결과물 위치와 상태를 `docs/STATUS.md` 에 한 줄 (만드는 중 / 사람 확인 대기 / 올림)

**안 쓰는 것** — `docs/engines/`, `docs/checks/`, `tools/check_conventions.py` 의 엔진 규칙, 스킬 `new-script`·`new-content`·`new-visual`·`reference-sheet`.

**이 종류의 함정**
- "만들었다" 와 "올렸다" 는 다른 조각이다. 올리기는 사람이 한다 → `[!] 사람: 올리기`.
- 조회수·반응은 루프가 못 만든다. 합격 기준에 넣지 않는다 (넣으면 영원히 `[ ]`).
- 생성 도구가 실패하면 같은 요청을 반복하지 않는다 — `unblock` 사다리.
