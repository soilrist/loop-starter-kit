# 프로필: general

**언제** — 다른 프로필에 안 맞을 때: 조사·보고서·데이터 분석·문서 정리·한 번짜리 일.

**결과물** — 맡긴 사람이 바로 쓸 수 있는 파일 하나 (보고서·표·정리된 폴더). 조각 하나 = 그 파일의 한 부분이 **근거와 함께** 끝난 것.

**검사 3층**
| 층 | 여기서 뜻하는 것 |
|---|---|
| 1 기계 | 파일이 열린다 + 형식이 맞다 (표 칸 수, 링크 형식, 빈 칸 없음) — 명령 출력으로 |
| 2 동작 | **다시 계산·다시 열기**: 숫자는 원자료에서 한 번 더 뽑아 맞추고, 링크·인용은 실제로 열어 본다 |
| 3 눈 | 완성본을 처음부터 읽고 아래 다섯 칸 |

**쓰는 사람 눈 다섯 칸** (이걸 받는 사람이라 치고)
1. 첫 세 줄에 결론이 있는가
2. 모든 숫자·주장에 어디서 왔는지 붙어 있는가
3. 모르는 것·확인 못 한 것이 "모름" 으로 적혀 있는가 (지어낸 것 없음)
4. 받는 사람이 다음에 할 일이 분명한가
5. 빼도 되는 문단이 없는가

**이 종류의 🔴** — 바깥으로 보내기·공개하기, 원본 자료 고치기·지우기, 돈 드는 조회, 개인정보를 밖으로 내보내기.

**여는 문서·스킬**
- 스킬: `build-slice`, `unblock`
- 설계서: `docs/DESIGN.md` — §1 누가 왜 필요한가, §5 결과물 목록, §10 안 하는 것. 나머지 절은 비워 둔다

**안 쓰는 것** — `docs/engines/`, `docs/checks/`, 게임 규칙·게임 스킬 전부.

**이 종류의 함정**
- 검사할 명령이 없다고 검사를 건너뛰지 않는다. "다시 계산·다시 열기" 가 2층이다.
- 세 바퀴 넘게 `general` 로 돌면 맞는 프로필이 생긴 것이다 → 바꾸거나 새로 만든다 (`profiles/README.md`).
