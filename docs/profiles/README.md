# 프로필 — 이 프로젝트가 어떤 종류의 일인가

> 키트의 뼈대(파일 기억·신호등·검사 3층·루프)는 어떤 일에도 같다. **종류마다 다른 것만** 프로필에 적는다.
> 일꾼은 `CLAUDE.md` 의 `프로필:` 칸에 적힌 파일 **하나만** 읽는다. 나머지 프로필은 열지 않는다 (토큰).

| 프로필 | 이런 일 | 파일 |
|---|---|---|
| `game` | 게임 (Unity·Unreal·Godot·웹 게임) | `game.md` |
| `app` | 웹·앱·서버·API·CLI·라이브러리 | `app.md` |
| `content` | 영상·쇼츠·글·이미지·채널 운영 | `content.md` |
| `automation` | 자동화·스크래핑·주문 처리·예약 작업·브라우저 조작 | `automation.md` |
| `general` | 위 어디에도 안 맞음 / 조사·문서·데이터 분석 | `general.md` |

## 고르는 법 (설치할 때 한 번)
1. 저장소에 엔진 마커(`ProjectSettings/`, `*.uproject`, `project.godot`)가 있으면 `game`.
2. `package.json`·`pyproject.toml`·`go.mod`·`Cargo.toml` 등 **실행되는 코드가 결과물**이면 `app`.
3. 결과물이 **사람이 보는 파일**(영상·글·이미지)이거나 올리는 채널이 있으면 `content`.
4. 결과물이 **바깥 서비스에 일어난 변화**(주문·등록·수집된 표)면 `automation`.
5. 모르겠으면 `general` 로 시작하고, 세 바퀴 안에 맞는 것으로 바꾼다.

## 섞인 프로젝트
- 기본은 `CLAUDE.md` 의 `프로필:` 하나. 다른 종류의 조각만 ROADMAP·INBOX 줄 끝에 `〔프로필: content〕` 를 붙인다.
- 일꾼은 꼬리표가 있으면 그 조각에서만 그 프로필을 읽는다.

## 프로필 파일의 칸 (전부 같다)
언제 / 결과물 / 검사 3층이 여기서 뜻하는 것 / 쓰는 사람 눈 다섯 칸 / 이 종류의 🔴 / 여는 문서·스킬 / 안 쓰는 것

## 새 프로필 더하기
`general.md` 를 복사해 일곱 칸을 채운다. 40줄을 넘기지 않는다. 표에 한 줄 더한다.
같은 실수가 두 번 나오면 그 프로필의 "이 종류의 함정" 에 한 줄 더한다 (CLAUDE.md 함정과 같은 규칙).
