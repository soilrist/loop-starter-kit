# Routing — 어떤 말이 와도 길을 찾는다

> 세 가지를 한 장에: **① 무엇으로 할지 고르기 ② 막혔을 때 내려가는 사다리 ③ 토큰 아끼기.**
> 감독·일꾼 둘 다 쓴다. 막혔을 때와 스킬을 고를 때만 연다 (매 바퀴 읽지 않는다).

## 1. 고르기 — 말 → 길

먼저 **어떤 종류의 말인지** 한 줄로 정한다. 그다음 표에서 맨 위에 맞는 줄 하나.

| 말의 종류 | 길 |
|---|---|
| 새 프로젝트·방향 정하기·"뭘 만들지" | 스킬 `kickoff` |
| 사람의 불만·지시·답을 받아 적기 | 스킬 `inbox` |
| 무언가 만들기·고치기 (조각 하나) | 프로필이 가리키는 스킬 → 없으면 `build-slice` |
| 게임: 스크립트 / 콘텐츠 / 보이는 것 / 레퍼런스 | `new-script` / `new-content` / `new-visual` / `reference-sheet` |
| 막힘·같은 실패 두 번·도구가 없음 | 스킬 `unblock` (아래 사다리) |
| 커밋 | 스킬 `commit` (사람이 부를 때) — 루프는 PROMPT ⑤ |
| 내보내기·버전 올리기 | 스킬 `release` (감독·사람) |
| 질문·설명 요청 | 스킬 없이 바로 답. 파일은 필요한 줄만 |
| 표에 없음 | **그래도 한다** — 아래 "표에 없는 일" |

**고르는 규칙**
1. 스킬 설명(description)만 보고 고른다. 본문은 **고른 하나만** 연다.
2. 맞는 스킬이 둘이면 더 좁은 것. 여전히 둘이면 순서대로 둘 다 (만들기 → 검사).
3. 프로젝트 `.claude/skills/` 가 먼저다. 전역 스킬은 루프에 안 실린다 (`LOOP_LEAN`).
4. 스킬이 없다고 멈추지 않는다. 스킬은 지름길이지 허가증이 아니다.

**표에 없는 일** — 어떤 일이든 이 다섯 줄로 조각이 된다:
1. 끝난 모습을 한 줄로 (합격 기준 = 눈으로·명령으로 확인되는 것)
2. 그걸 확인할 방법을 먼저 정한다 (프로필의 검사 3층)
3. 10분 안팎 조각으로 자른다. 첫 조각만 한다
4. 신호등을 본다 (`Autonomy.md` + 프로필의 🔴)
5. 하고, 인용하고, 적는다

## 2. 사다리 — 막혔을 때 (절대 그냥 멈추지 않는다)

위에서부터. **한 칸에서 두 번 실패하면 다음 칸.** 같은 걸 세 번 하지 않는다.

| 칸 | 할 일 |
|---|---|
| 1 읽기 | 에러 글을 **끝까지** 읽는다. 글 그대로 저장소·로그에서 찾는다 (`grep`) |
| 2 좁히기 | 가장 작은 재현 하나. 마지막으로 되던 커밋과 무엇이 다른지 (`git diff`, `git log -5`) |
| 3 다른 도구 | 같은 목적의 다른 길: 다른 명령·다른 라이브러리·MCP 대신 CLI·CLI 대신 파일 직접 |
| 4 찾기 | 공식 문서·검색 (도구가 있으면). 버전을 적고 찾는다 |
| 5 돌아가기 | 목표를 지키고 방법을 바꾼다: 범위를 줄인 조각으로 다시 자르기, 가짜(목)로 먼저 잇기 |
| 6 넘기기 | 이 조각을 `[!]` + **해 본 것·남은 가설·다음에 할 사람이 볼 곳** 으로 적고, **다음 조각으로 간다** |

- 6칸은 멈춤이 아니다. 루프는 계속 돈다. 사람이 필요한 것만 `[!] 사람:` 으로 올린다.
- 🔴 에 닿은 것은 사다리가 아니다 → 바로 6칸 (`Autonomy.md`). 돌아가는 길을 찾지 않는다.
- 사다리를 탄 기록은 커밋 본문이나 `docs/bugs/` 에 세 줄: 증상 / 원인 / 고친 것. 같은 막힘이 두 번이면 `CLAUDE.md` 함정에 한 줄.
- 환경 문제(도구 없음·권한·OS 차이)는 고치려 들기 전에 **있는 것으로 하는 길**을 먼저 찾는다 (예: `python3` 없음 → `python`, `timeout` 없음 → 키트의 `run_with_timeout`).

## 3. 토큰

| 규칙 | 왜 |
|---|---|
| 큰 파일은 `grep` 으로 줄을 찾고 그 근처만 읽는다 | 통째로 읽으면 바퀴마다 다시 실린다 |
| 이번 바퀴에 읽은 파일은 바뀌지 않았으면 다시 읽지 않는다 | |
| 긴 출력은 `tail -n 40` — `head` 로 자르지 않는다. 인용은 **결과 줄**만 | 결과 줄은 끝에 있다. 앞을 자르면 다시 돌리게 된다 |
| 줄여 주는 도구(rtk 등)를 거친 출력에서 못 찾으면 `logs/` 의 원본을 `grep` | 줄인 글을 다시 뒤지지 않는다 |
| STATUS 는 `## 지금 상태` 절만, INBOX 는 루프가 처리할 줄만 (`grep -n '^- \[ \] \(결함\|지시\|답\|보정\|철회\)('`) | 통째로 읽으면 수천 줄이 매 바퀴 든다 |
| 컨텍스트가 압축된 뒤에는 STATUS "지금 상태"만 다시 읽는다 | 압축마다 전부 다시 읽으면 압축한 보람이 없다 |
| 되풀이해 넣는 긴 지시는 파일에 두고 "〔파일〕대로" 한 줄로 부른다 | 같은 긴 글이 한 세션에 쌓여 압축이 난다 |
| 여럿이 보는 검토(심판 등)는 정한 인원을 넘기지 않는다. 하나가 죽으면 그 하나만 다시 돌린다 | 전부 다시 돌리면 두 배 |
| 프로필은 하나만, 스킬 본문은 고른 하나만 | |
| "안 쓰는 것" 에 적힌 문서는 열지 않는다 | 프로필마다 적혀 있다 |
| 쉬운 조각엔 싼 모델 — `LOOP_MODEL="auto"` (`loop/pick_model.py`) | 어려운 줄에만 비싼 모델 |
| 문서가 불면 `loop/ctl.sh tidy` — STATUS "지금 상태" 25줄 | 매 바퀴 읽는 값 |
| 하위 에이전트는 사람이 시킬 때만 | 컨텍스트가 통째로 한 번 더 든다 |

## 4. 실수 줄이기 (한 줄씩)
- 바꾸기 전에 본다: 지울·덮을 대상을 먼저 읽는다.
- 했다고 쓰기 전에 본다: 명령 출력을 인용 못 하면 "안 됨" 이다 (`Verification.md`).
- 추측을 사실처럼 쓰지 않는다: 모르면 "모름 — 확인 방법: …".
- 한 번에 하나: 조각 하나, 커밋 하나, 바꾼 이유 하나.
- 출력이 비면 "통과"가 아니라 "못 돎"이다: 명령이 있는지(`command -v`)부터 본다. 찾은 도구 경로는 STATUS "검사 명령" 칸에 적는다.
- 로그는 날짜가 아니라 **이번 런** 것인지부터 본다: `loop/ctl.sh status` 의 마지막 바퀴 번호·시각과 맞는 로그만.
- INBOX·STATUS 를 옮기거나 보관할 땐 줄 번호가 아니라 **항목 단위**(`- [ ]` 한 덩어리, `## #` 한 바퀴)로 옮긴다.
- 기록에 적는 그림 묘사는 캡처를 **연 뒤 본 대로** 적는다 (의도·기억으로 적지 않는다).
- 같은 "할 일 없음"·"막힘 재확인"을 두 번 적지 않는다. 바뀐 게 없으면 적지 않고 끝낸다.

## 5. 보고 길·가벼운 일·말투
- **세션끼리 주고받는 통로는 파일이다.** 루프 → 감독 = STATUS·INBOX, 감독 → 루프 = INBOX `지시`. 세션 메시지는 보조다 (보관된 세션·다른 기기엔 안 닿는다).
- **위로 올리는 보고**(부모 세션·사람)는 세 줄: 한 것 / 문제 / 정할 것. 루프가 있으면 맨 앞에 도는 중인지 멈췄는지 한 마디 (`loop/ctl.sh status`).
- **문서만 바꾸는 일**(판결문·INBOX 정리·보고서·규칙 문서): 1층(규칙 검사) + 바꾼 문서를 다시 읽기까지만. 2층·3층 캡처·눈 다섯 칸·jev 판정은 `해당 없음` 한 마디로 적는다. 바퀴 기록도 한 것·커밋 두 줄이면 된다.
- **되풀이하는 운영 일**(매일 보고·정리)은 ROADMAP 조각이 아니다. 감독이 때마다 INBOX `지시` 로 넣는다 (예약 도구가 있으면 그것으로).
- **말투가 서로 다르면**: 사람의 전역 지시·메모리 > 프로젝트 `CLAUDE.md` > 출력 스타일.
