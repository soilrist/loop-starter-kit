# ROADMAP — 순서

> 루프는 **INBOX 에 할 일이 없을 때** 여기서 맨 위의 안 끝난 조각을 집는다.
> 조각 = 커밋 하나 크기(10분 안팎). **ID 는 한번 붙이면 안 바꾼다** — 커밋 꼬리말 `Slice: M0-02` 로 추적한다.
> 체크는 루프가 커밋 후 `[x]` 로. 마일스톤이 전부 `[x]` 면 감독이 `release` 제안 → 버전 `0.<M>.0`.
> 🔴 로 막힌 조각은 `[!]` + 이유, 루프는 건너뛴다. **사람만 할 수 있는 조각**(계정 콘솔·결제·엔진 설치)은 `[!] 사람: <할 일> — 기다리는 마일스톤: M2, M3` 로 적는다 → 감독 보고 맨 앞.
> 콘텐츠 종류(DESIGN §5)마다 마일스톤이 하나씩은 있어야 한다 (`conventions/Reference.md` §1). 보이는 조각의 합격 기준엔 "레퍼런스 시트 대조 통과"가 들어간다.
> **마일스톤마다 마지막 두 조각**: `M<n>-처음 하는 사람 통 플레이` (새 세이브·기본 지급품·목표 기기 입력으로 이 마일스톤 기능을 처음부터 지나가는 테스트 — `conventions/PlayerEye.md`) 와 `[!] 사람: 🎮 M<n> 5분 해 보기 — 계속 / 고쳐`. 사람이 안 해 본 마일스톤이 2개 쌓이면 감독이 루프를 멈춘다 (DIRECTOR.md).

## M0 — 뼈대 (합격: 빈 화면에서 캐릭터 대신 네모가 입력대로 움직인다) 〔예시 — 엔진별 구체 방법은 `docs/engines/<엔진>.md`〕
- [ ] M0-01 폴더 구조·모듈 뼈대(Unity=asmdef, Unreal=모듈, Godot=오토로드) — 합격: 검사기 통과, 컴파일 0 에러
- [ ] M0-02 Boot → Title → Game 화면 흐름 — 합격: 실행 시 Game 화면까지 자동 진입
- [ ] M0-03 입력 바인딩(Unity=Input Action, Unreal=Enhanced Input, Godot=Input Map) + 이동 — 합격: 2층 검사(`docs/checks/<엔진>.md`)로 키 입력 시 위치 변화 확인
- [ ] M0-04 카메라 따라가기 — 합격: 캡처에서 네모가 화면 중앙
- [ ] M0-05 검사 파이프라인 — 합격: 1층 통과, 2층 테스트 1개 통과(엔진별 테스트 도구는 `docs/checks/<엔진>.md`), `DataIntegrityTests` 뼈대
